# 工作流C：框架模板生成 — 详细输出模板

## 输入要求

- **题型**：六题型之一
- **方法论**：该题型的方法论段落（工作流B输出）

## 输出模板

输出匹配讲义"二、答题框架模板"结构的段落，格式如下：

```markdown
## 二、答题框架模板

### 1. 完整结构

```
【破题】
{一句话点破本质，反常识/反模板，10-20字}

【展开】
第一层：{观点/阶段1}
  - {具体展开要点，2-3句}
  - {数据/案例支撑}

第二层：{观点/阶段2}
  - {具体展开要点，2-3句}
  - {数据/案例支撑}

第三层：{观点/阶段3}
  - {具体展开要点，2-3句}
  - {数据/案例支撑}

【收尾】
{一句话收束，落到行动或价值升华，15-25字}
```

### 2. 变体

**变体A：{变体名称}**
适用场景：{什么情况下用这个变体}
```
{变体结构，与完整结构格式一致}
```

**变体B：{变体名称}**（可选）
适用场景：{什么情况下用这个变体}
```
{变体结构}
```

### 3. 结构要点

1. {要点1：关于破题的具体要求}
2. {要点2：关于展开层次的要求}
3. {要点3：关于收尾的要求}
4. {要点4：关于时间分配的建议}
5. {要点5：关于与题型匹配的要求}
```

## 流程详解

1. **读取方法论**：理解该题型的核心方法论要点
2. **设计骨架**：基于方法论设计答题框架的完整结构
3. **生成变体**：根据不同出题方向设计 1-2 个变体
4. **提取要点**：从框架中提取 4-6 条结构要点
5. **验证**：运行 `python <skill目录>/scripts/validate_question.py "<文件>" --mode framework`
6. 🔴 **CHECKPOINT**：展示完整框架模板给用户确认

## 质量要求

- 完整结构必须有【破题】和【收尾】标记
- 代码块内占位说明至少 3 处
- 变体必须说明适用场景
- 结构要点必须可操作，不写"要有逻辑"这种废话
- AI痕迹零命中
