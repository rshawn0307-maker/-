## 流程详解

### 1. 读取现有讲义

- 读取讲义文件，解析章节结构
- 识别各章节的起止行号
- 记录当前章节数量和编号

### 2. 识别需更新章节

根据用户需求确定操作：
- **新增章节**：在指定位置插入新章节内容
- **修改章节**：替换指定章节的内容
- **删除章节**：移除指定章节（需用户明确确认）

### 3. 增量更新

🔴 **铁律：大文件（>100KB）禁止整文件重写，必须用 SearchReplace 做增量修改**

- 新增章节：在上一章末尾插入新章节
- 修改章节：定位章节起止，替换内容
- 删除章节：定位章节起止，移除内容

### 4. 更新前言

- 更新章节数量描述（如"本讲义共9章"）
- 更新目录结构说明
- 更新使用说明（如有新功能）

### 5. 更新 frontmatter

- `updated` 字段更新为当前日期

### 6. 验证整体结构

```bash
python <skill目录>/scripts/validate_question.py "<讲义文件>" --mode lecture --expected-chapters {N}
```

N 为期望章节数：
- 更新前验证：N=8（现有8章）
- 插入第九章后验证：N=9

### 7. 🔴 CHECKPOINT

展示更新摘要给用户确认：
- 新增/修改/删除了哪些章节
- 章节编号是否连续
- 验证结果（字数/AI痕迹/结构）

### 8. 写入讲义文件

用户确认后写入。写入后再次跑验证确认。

## 注意事项

- **章节编号连续**：第一至第N章必须连续，不能跳号
- **题型章结构一致**：每个题型章必须含"答题方法论""答题框架模板""例题汇编"三节
- **前言一致性**：前言中描述的章节数量必须与实际一致
- **嵌入题目验证**：讲义中使用 `#### 答题逐字稿`（四级标题），验证脚本会自动提取并逐个验证
- **大文件编辑**：888KB讲义文件必须分段读取 + SearchReplace 修改，不整文件重写
- **备份**：更新前先备份原讲义文件（复制为 `.bak` 后缀）
