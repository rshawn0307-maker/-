# 工作流E：素材库生成 — 详细输出模板

## 输入要求

- **主题**：素材的主题关键词（如"银发经济""反诈治理"）
- **题型**（可选）：六题型之一，或"通用"
- **素材类型**：四类之一
  - 政策文件摘要
  - 典型案例故事
  - 高分金句语录
  - 热点数据统计

## 素材 md 模板

```markdown
---
type: 素材
素材类型: {政策文件摘要|典型案例故事|高分金句语录|热点数据统计}
题型: {综合分析|组织计划|人际关系|应急应变|自我认知|言语表达|通用}
主题: {主题关键词}
来源: {来源说明}
updated: {日期}
tags:
  - 类型/素材
  - 业务线/公考结构化
  - 素材类型/{素材类型}
---

# {素材标题}

## 素材内容

{按素材类型规范的内容}

## 适用场景

{哪些题型、什么主题可使用，给出2-3个题目示例}

## 使用建议

{如何在答题中引用此素材，给出1-2个引用示例}
```

## 四类素材详细规范

### 1. 政策文件摘要

| 项目 | 要求 |
|------|------|
| 内容结构 | 文件全称 + 发布机构 + 发布时间 + 3-5条核心要点 + 关键数据 |
| 字数范围 | 200-400字 |
| 来源要求 | 必须标注文件全称和发布时间 |
| 示例 | 《关于发展银发经济增进老年人福祉的意见》（国务院办公厅，2024年1月） |

**内容模板**：
```
文件全称：《{文件名称}》
发布机构：{机构名称}
发布时间：{年月}

核心要点：
1. {要点1}
2. {要点2}
3. {要点3}
4. {要点4}（可选）
5. {要点5}（可选）

关键数据：{数据内容}
```

### 2. 典型案例故事

| 项目 | 要求 |
|------|------|
| 内容结构 | 背景(50字) + 经过(100字) + 结果(50字) + 启示(50字) |
| 字数范围 | 250-400字 |
| 来源要求 | 标注案例来源（新闻报道/官方通报/实地调研等） |

**内容模板**：
```
【背景】{50字以内描述案例背景}
【经过】{100字左右描述关键过程，聚焦做法而非流水账}
【结果】{50字以内描述成效，用数据说话}
【启示】{50字以内提炼对面试答题的启示}
```

### 3. 高分金句语录

| 项目 | 要求 |
|------|------|
| 内容结构 | 金句原文 + 适用场景 + 使用注意 |
| 字数范围 | 50-150字 |
| 来源要求 | 标注来自哪道题或原创 |

**内容模板**：
```
金句：「{金句原文}」
来源：{来自哪道题/原创}
适用：{什么题型、什么主题适用}
注意：{使用时的注意事项，如不要生硬套用}
```

### 4. 热点数据统计

| 项目 | 要求 |
|------|------|
| 内容结构 | 数据来源 + 数据内容 + 趋势解读 |
| 字数范围 | 100-250字 |
| 来源要求 | 必须标注数据来源和年份 |

**内容模板**：
```
数据来源：{来源机构/报告名称}，{年份}
数据内容：
- {数据点1}：{具体数字}
- {数据点2}：{具体数字}
- {数据点3}：{具体数字}
趋势解读：{1-2句解读数据背后的趋势和含义}
```

## 流程详解

1. **确定主题**：根据用户需求或热点话题确定素材主题
2. 🔴 **CHECKPOINT**：选题清单呈现给用户确认
3. **按规范生成**：根据素材类型对应规范生成内容
4. **验证**：运行 `python <skill目录>/scripts/validate_question.py "<文件>" --mode material`
5. 🔴 **CHECKPOINT**：展示完整素材内容给用户确认
6. **写入文件夹**：按输出目录写入，`mkdir -p` 创建不存在的文件夹

## 质量要求

- frontmatter 字段完整：type/素材类型/题型/主题/来源/updated/tags
- 素材类型为4种之一
- 含"素材内容""适用场景""使用建议"三段
- 字数符合类型要求
- 来源标注完整
- AI痕迹零命中（素材内容段落）
- 数据必须标注年份和来源，不编造数据
