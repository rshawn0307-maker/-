# 工作流D：过渡句生成 — 详细输出模板

## 输入要求

- **题型**：六题型之一，或"通用"
- **题库样本**：该题型现有逐字稿（用于提取过渡句）

## 输出模板

输出匹配讲义第七章结构的段落，按功能分类：

```markdown
### {题型}过渡句

#### 破题开场

1. {过渡句1}
2. {过渡句2}
3. {过渡句3}

#### 引出原因

1. {过渡句1}
2. {过渡句2}
3. {过渡句3}

#### 深层分析

1. {过渡句1}
2. {过渡句2}
3. {过渡句3}

#### 对策推进

1. {过渡句1}
2. {过渡句2}
3. {过渡句3}

#### 收尾升华

1. {过渡句1}
2. {过渡句2}
3. {过渡句3}
```

## 流程详解

1. **扫描逐字稿**：读取该题型所有逐字稿
2. **按功能分类提取**：
   - 破题开场：开篇引出话题的句子
   - 引出原因：从现象过渡到原因分析的句子
   - 深层分析：从表层原因深入到本质的句子
   - 对策推进：从分析过渡到对策的句子
   - 收尾升华：结尾总结升华的句子
3. **去重去AI痕迹**：相同意思的只保留最佳表述；清除"总之""综上"等AI万能收束
4. **按频率排序**：高频使用的排前面
5. **验证**：确认每类至少 3 条，无AI痕迹
6. 🔴 **CHECKPOINT**：展示完整过渡句库给用户确认

## 质量要求

- 每类至少 3 条过渡句
- 过渡句必须来自真实逐字稿，不编造
- 去重：相同意思的不同表述只保留最佳的一条
- 无"总之/综上/综上所述"收尾
- 无AI痕迹（标志性短语、三段式、破折号残留等）
- 句子长度 10-30 字为宜，口述感强
