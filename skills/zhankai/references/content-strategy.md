## 考官视角核心

**核心定位**：本号不是教"如何答一道题"，是**站在考官视角剖析"一道题应该怎么答"**--把"考官想听什么"翻译成"考生能用的视角"。

### 考官真正想听什么

公务员结构化面试，**1 个考官 1 天听 30+ 个考生，平均 1.5 分钟定生死**。他们想要的不是"标准答案"，是：

- **有观点**：敢下判断，不中庸。"我怎么看这件事" > "利弊分析"
- **有逻辑**：观点有支撑链，但**逻辑≠"首先/其次/最后"那种流水线**--是有"机制阐释"的能力
- **有表达**：语言鲜活有节奏，读出来像"真人在讲"，不是书面体也不是网络体
- **有深度**：能看到"机制层"（为什么这样），不是停在"现象层"（这样不好）
- **可操作**：对策要能落地--"街道设 1 个'老人陪同岗'，每天上午 9-11 点"，不是"加强宣传"
- **接地气**：用"街道办""90 后网格员""社区民警"这种具象词，不是"基层干部""人民群众"

### 考官最反感的 5 种答法（避坑反面）

| 类型 | 典型表现 | 为什么差 |
|---|---|---|
| **假大空** | "体现了以人民为中心的发展思想" | 没具体指向，说了等于没说 |
| **套路化** | "凡事预则立，不预则废"开场 | 30 个考生 25 个这么说，考官已麻木 |
| **空喊口号** | "加强、完善、推进、落实"四个动词堆 | 没动作主语、没时间、没可衡量 |
| **辩证式中庸** | "这事有利有弊，要辩证看" | 等于没观点，不敢站队 |
| **背模板** | "戴了三个帽子：理论/实践/个人" | 一听就是培训班的，扣差异化分 |

### 重新定位 3 层 / 5 段 / 四步法

骨架还是这个骨架，**但它的角色从"答题模板"升级为"分析视角"**--脚手架不能拆，但**观点和论证才是肉**：

| 旧框架（填空模板） | 新框架（分析视角） | 核心变化 |
|---|---|---|
| 3 层 30/40/30（机械分段） | **3 个递进分析视角** | 比例可灵活，但必须有"真相->机制->对策"的递进 |
| 5 段增值（必填 5 段） | **5 个补充视角** | 可选可不选，缺哪个视角就补哪个 |
| 考场四步法（① 定性 ② 析因 ③ 述害 ④ 出招） | **答题动作拆解** | 4 步是"我做了什么思考动作"，不是"我说了哪句话" |
| 扣题技巧（3 场景换"魂"） | **场景化落地** | 不是空泛对策，是"街道怎么干/乡镇怎么干/机关怎么干" |

**原则**：骨架是脚手架，**观点和论证才是肉**。脚手架不能拆，但肉可以自由生长--只要有 1 个让考官"眼前一亮"的判断，整体就立住了。

## 小红书表达规范（必读）

> 本号内容是发在小红书上的长帖，不是公众号讲义。**考官视角拆解是内核，小红书节奏是外壳**：深度不能丢，表达必须按平台习惯来。

### 1. 标题钩子（cover_title）

- **≤12 字**（脚本硬上限 20 字），必须含**数字 / 反差 / 悬念 / 利益**之一。
- 禁止纯主题词：`"政务夜市"` 不合格；`"夜市凉了，问题不在夜市"` 合格。
- 封面文本框只放标题本身，不在标题里写"展开说说""第 N 期"等栏目词。

### 2. 开场 3 秒（段[1-4]）

- one_liner 用**判断句**直接给观点；"不是 X，是 Y"全篇最多 1 次，开场用过后面不再用。
- hook_1/hook_2 必须带**真实考场细节**：考官一天听 30+ 人、1.5 分钟定生死、评分表维度、雷同开场扣分、低头看表。禁止空喊"考官想听的是…"。
- main_thread 用口语预告结构："这篇拆 3 件事：…"，不写"展开围绕一条主线"。

### 3. 段落节奏（所有正文段）

- **单段 ≤4 行（docx 内用软换行），行内 ≤30 字**；短句 8-20 字为主，长句必须拆。
- 数字一律阿拉伯数字（"30 个考生"不写"三十个考生"）。
- emoji 每段 ≤2 个，限用调色板：`❗️ 🙅 ❌ ✅ 📌 💡 ⏰ 🗣`；禁止无意义堆砌。
- 每屏一个核心信息：段与段之间靠短句呼吸，不靠"第一/第二/第三"连接。

### 4. 互动与收藏

- `cta_hook`（段[39]）20-40 字，**必须提问收口**："你在考场上会怎么答？评论区聊聊，我帮你挑刺。"禁止"谢谢观看"。
- 金句段、对比卡段保持**独立成段可截屏**；结尾 CTA 可含"先收藏，考前一晚再看"。
- 全文 CTA ≥ 2 处：开场钩子后 1 处（可选，轻），cta_hook + 引流段收尾。

### 5. 话题标签（hashtags）

- 5-8 个，空格分隔，每个以 `#` 开头。
- 固定 3 个：`#公考面试 #结构化面试 #考官视角`；其余按当期题型/主题补 2-5 个（如 `#综合分析题 #政务夜市 #面试逆袭 #考公上岸`）。
- 标签写实，不蹭与内容无关的热门标签。

### 6. 数据纪律

- 数字钉子必须**可核验**：公开来源（政策文件/新闻/官方数据）或**明确标注"举例"**。
- **禁止编造百分比和统计**（如"73% 不会用"必须有出处，否则写"我见过的大多数窗口…"并标举例）。

### 7. 听感自检

- 写 JSON 前把全文大声读一遍：读起来像人话才过。
- 书面连接词（此外/值得注意的是/与此同时）、"第一步/第二步"腔调、破折号滥用，一律改口语。
- 每段最多 1 个破折号，且必须是真的解释。

## 内容算法

**算法分 3 部分**：A. 数字钉子/节奏/钩子（保留）；B. 去 AI 化·human-writing 红线（**新增**）；C. 公考词汇合规（**新增**）。

### 1. 数字钉子（必带）
- **30/40/30 比例**（用在 3 层结构时）
- **30/45/60/20 秒**（4 步法骨架时，新模板默认）
- **3 个错位 / 3 个不匹配 / 3 个剥夺**（析因/述害的钉子数）

### 2. 命名节奏（按主题择用）
- **"Air/Pro/ProMax" 升级钉**（适合"做法/技术"类题）
- **"X 错位 / X 剥夺 / X 校正"**（适合"现象-机制"类题）
- **"X 个'不匹配'"**（适合"群体-系统"类题）

### 3. 钩子反转（开头 3 秒决定 70% 完读率）
- **"不是 X，是 Y"** 对立反转（**最常用**）
- **"X 发了上百份，Y 反而越来越多"** 事实反转
- **"X 装了 Y，Z 测了 W"** 对比反转

### 4. 金句密度
- **几乎每节结尾都有一句可截屏**--**截图率= 收藏率= 算法权重**
- **金句公式**："X 不是 Y，是 Z" / "X 不是为了 Y，是为了 Z" / "X 决定 Y"

### 5. 避坑红线
- **每期 2-5 句"绝对不能说的官话"**（如"基层要敢于担当""减负不减责"）
- **这是"赚到感"的关键**--读者觉得"学到课本外的东西"

### 6. 扣题技巧（增值动作）

- **不同场景换不同的"魂"**（如街道/乡镇/机关的对策颗粒度不同）
- **3 场景是甜区**--不多不少

## 去 AI 化红线

**流程**：生成草稿 -> 按 human-writing 的 SKILL.md 与 `references/revision.md` 的规则自查 -> 改写问题片段 -> 入 JSON。

**绝对禁止的 AI 模式**（公考面试语境下的高危版）：

| 类别 | 红线示例 | 公考面试改写 |
|---|---|---|
| **填充短语** | "为了实现这一目标""值得注意的是" | "为了 X" / "X 数据显示" |
| **AI 词汇** | 此外、至关重要、深入探讨、强调、培养、获得、突出、相互作用、复杂性、关键（形容词）、格局、宝贵的、持久的 | 用具体动词："培养"->"教" / "格局"->"布局" |
| **否定式排比** | "不仅...而且..." "这不仅仅是...而是..." | 改直接陈述："A 是 B" 而非 "A 不仅是 B，更是 C" |
| **三段式法则** | 强行把 2 件事扩成 3 件凑数 | **2 件就 2 件，4 件就 4 件，不要凑 3**--人类不这么讲话 |
| **破折号滥用** | "--" 每句结尾 | 1 段最多 1 个破折号，且必须是真的解释 |
| **粗体滥用** | 1 段 3-4 个 **重点词** | 粗体只用于"金句"和"关键数字" |
| **否定式排比钩子** | "不是 X，是 Y" 套 3 段 | **保留 1 段**作开篇钩子即可，后面别再"不是...是..." |
| **模糊归因** | "专家认为""观察者指出" | 给出具体出处或直接删 |
| **合作交流痕迹** | "希望对您有帮助" "请我告诉" | **教程化语言禁止**--这是小红书长帖不是聊天 |
| **过度限定** | "可能会""或许可以" | 公考要敢下判断，但论证要扎实 |
| **通用积极结论** | "未来可期""前景光明" | 用具体行动或时间点替换 |

**特别注意公考领域的"AI 味儿"高危词**（一字不差禁用）：

- **"体现/彰显/凸显"** -> 改 "X 表明" / "X 是因为" / 直接说事实
- **"深入推进/全面落实/持续优化"** -> 给出谁、什么时间、做什么
- **"多措并举/综合施策/协同推进"** -> 列出具体几条
- **"切实保障/有效提升/有力推动"** -> 给出可量化指标

## 公考词汇合规

| 类型 | ✅ 用 | ❌ 别用 |
|---|---|---|
| **政策概念** | "放管服改革""一网通办""网格化治理""属地管理" | 自创缩写、没出处的概念 |
| **角色** | "街道办""90 后网格员""社区民警""驻村第一书记" | "基层干部""人民群众""相关部门" |
| **动作** | "设 1 个'陪同扫码岗'""保留 3 个现金窗口" | "加强 / 完善 / 推进 / 落实" |
| **数据** | "60 岁以上 73% 不会用健康码" | "绝大多数""大部分""不少" |
| **判断** | "73% 不会 ≠ 73% 不想学" | "X 是因为 Y" 的伪因果 |

## 金句公式

去 AI 味儿原则提醒："如果听起来像可引用的语句，重写它"--但公考面试要金句（截图率=收藏率=算法权重），所以**重新定义"好金句"**：

**好金句 3 特征**：
1. **有判断**--"给翻译层，不给长衫"（不是"我们要重视教育"）
2. **有对比**--"不是 X，是 Y"（**一个就够，别 3 段都用**）
3. **有具体**--"凌晨 3 点的健康码"（不是"深夜的守候"）

**反面金句**（AI 味儿重）："在 XX 的道路上，我们任重道远" / "时代是出卷人，我们是答卷人"。

## 选题策略

**不预设固定选题优先级**--每期开跑时按步骤 1 的流程动态搜索选题：

1. **用户指定岗位** -> 搜该岗位相关热点
2. **用户未指定** -> 搜近 1-2 周公务员面试热点话题 / 政策类新闻 / 社会现象
3. **避免**过于专业的岗位题材（除非用户指定）
4. **每次选 2-3 个**让用户选择

**历史选题参考**（仅做避重参考，不作为优先级排序）：

| 主题 | 题型 | 反常识破题 |
|---|---|---|
| 指尖上的形式主义 | 基层治理 | 考核方式在逼基层装忙 |
| 舆情反转 | 应急处突 | 第一次怎么说话比说什么更重要 |
| 被领导当众批评 | 人际沟通 | 别急着认错也别急着反驳 |
| 老同事不配合新领导 | 组织管理 | 先活下来再立规矩 |
| 老年人数字鸿沟 | 综合分析 | 谁在替老人做选择 |
| 优化营商环境 | 政策评价 | 企业视角 vs 政府文件视角 |

## 对比卡模式

> 步骤 1.5 选了"对比卡模式"时读取本节。
> 核心思路：把"考官视角分析"转化为"考生可直接用的低分 vs 高分对比"，降低读者认知门槛，提升截屏收藏率。

### 与常规模式的区别

| 维度 | 常规模式 | 对比卡模式 |
|---|---|---|
| 第二层 | 3 个倒错（机制层面：为什么错） | 3 个低分答法（考官视角：考生常犯的错） |
| 第三层 | 3 个校正（机制层面：怎么改） | 3 个高分答法（考官视角：应该怎么答） |
| 读者感受 | "原来问题出在这里" | "这就是我答过的方式！原来该这么说" |
| 截屏驱动力 | 金句驱动 | 对比驱动（低分 vs 高方放在同一视角下） |

### 内容编排规则

**段位表和 JSON 字段完全不变**。脚本不需要任何修改。只改变写入 JSON 的内容风格。

**第二层（段[10-16]）改写规则**：

| 段位 | 常规模式内容 | 对比卡模式内容 |
|---|---|---|
| 段[10] H2 | "第二层：3 个倒错，XXX" | "第二层：3 个低分答法，考官一听就扣分" |
| 段[11] 说明 | "为什么...？我分析有 X 个 Y" | "考官最反感的 3 种答法，你可能正在用" |
| 段[12] ❶ | "❶ 考核方式倒错：..." | "❌ 低分答法 1：\"...\"--考官内心：又来一个背模板的" |
| 段[13] ❷ | "❷ 责任归属倒错：..." | "❌ 低分答法 2：\"...\"--考官内心：说了一分钟没听到观点" |
| 段[14] ❸ | "❸ 技术应用倒错：..." | "❌ 低分答法 3：\"...\"--考官内心：假大空，直接划档" |
| 段[15] 关键 | "▲ 关键：..." | "▲ 关键：这 3 种答法的共同问题是..." |
| 段[16] 总结 | "一句话总结：..." | "一句话总结：考官不是在挑错，是在找差异化" |

**第三层（段[17-23]）改写规则**：

| 段位 | 常规模式内容 | 对比卡模式内容 |
|---|---|---|
| 段[17] H2 | "第三层：3 个校正，XXX" | "第三层：3 个高分答法，考官想听的就是这个" |
| 段[18] 说明 | "怎么破解" | "把上面 3 个低分答法翻过来，就是考官想听的" |
| 段[19] ❶ | "❶ 改考核：..." | "✅ 高分答法 1：\"...\"--考官内心：这个人有判断力" |
| 段[20] ❷ | "❷ 容错位：..." | "✅ 高分答法 2：\"...\"--考官内心：对策能落地" |
| 段[21] ❸ | "❸ 还时间：..." | "✅ 高分答法 3：\"...\"--考官内心：不是背的，是自己想的" |
| 段[22] 关键 | "▲ 关键：..." | "▲ 关键：高分答法的共同特征是..." |
| 段[23] 总结 | "一句话总结：..." | "一句话总结：考官要的不是标准答案，是差异化判断" |

### 对比卡模式的"考官内心"写法

低分答法后跟"考官内心：..."是对比卡的灵魂。写法要求：

- **不说教**：不写"这种答法不好因为..."，写"考官内心：又来一个背模板的"
- **有画面**：用考官的真实心理活动，如"考官低头看表""考官在评分表上画了个圈"
- **短而狠**：10-20 字，一句话点透为什么这个答法让考官减分

### 其他段位

第一层（段[5-9]）、5 段增值（段[24-38]）在两种模式下内容基本一致，不需要改写。对比卡模式的差异集中在第二层和第三层。

### 适合对比卡模式的题型

| 题型 | 为什么适合 |
|---|---|
| 人际沟通（被批评/不配合） | 考生容易答出"低分答法"，对比感强 |
| 应急处突（舆情/突发事件） | 正确应对 vs 错误应对天然形成对比 |
| 组织管理（活动组织/调研） | 流程化答题容易模板化，对比能突出差异 |

### 不太适合对比卡模式的题型

| 题型 | 为什么不适合 |
|---|---|
| 综合分析（政策评价/社会现象） | 需要深度机制分析，不是"答法对错"问题 |
| 哲理启示类 | 没有明确的"低分答法"，是理解深度问题 |
