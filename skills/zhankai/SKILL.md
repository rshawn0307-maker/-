# 考官想听的·展开说说·自动化长帖生成

## 适用场景

用户要做"公务员结构化面试·考官想听的·展开说说"系列小红书/公众号长帖（如拆解"指尖形式主义""应急处突""被领导当众批评"等题型），需要：

1. **拆解一个结构化话题**（用考官想听的角度，让考生知道如何答出差异化拉开差距）
2. **自动套入固定 docx 模板**（48 段 + 1 表格，含配图 + 互动钩子 + 话题标签 + 引流文案）
3. **保留模板所有版式**（封面图、装饰图、引流段样式）
4. **沿用算法**：3 层 30/40/30 + 5 段增值、钩子反转、X 句绝对不能说、扣题技巧（不同场景换魂）

### 步骤 0：模板段位真读取（**跑脚本前必跑**）

**铁律**：**任何模板的段位/ 文本框/ 表格结构都必须用 python-docx 真实读出**，**绝不能从 skill 描述/ 旧版记忆/ 口述脑补**。

读取脚本：

```python
from docx import Document
from docx.oxml.ns import qn
doc = Document(r"<模板路径>")
print(f"段数: {len(doc.paragraphs)}")
print(f"表格数: {len(doc.tables)}")
# 段+表+文本框 全 dump
body = doc.element.body
para_idx = table_idx = 0
for child in body.iterchildren():
    tag = child.tag.split('}')[-1]
    if tag == 'p':
        text = ''.join(child.itertext()).strip()[:50]
        imgs = len(child.findall('.//' + qn('w:drawing')))
        txbxs = len(child.findall('.//' + qn('w:txbxContent')))
        marker = f"🖼️{imgs}" + (f"📦{txbxs}" if txbxs else "")
        print(f"P[{para_idx:2d}] {marker:8s} | {text}")
        para_idx += 1
    elif tag == 'tbl':
        rows = child.findall('.//' + qn('w:tr'))
        first_row = rows[0] if rows else None
        cells = [''.join(c.itertext()).strip()[:30] for c in first_row.findall('.//' + qn('w:tc'))] if first_row is not None else []
        print(f"T[{table_idx}] 表格 {len(rows)}行×{len(cells)}列 | 表头: {' || '.join(cells)}")
        table_idx += 1
```

### 步骤 1：选题 + 拆题思路

**选题流程（不预设固定优先拆解清单，每期动态搜索）**：

1. **判断用户是否指定岗位**：
   - **用户指定岗位**（如"税务岗""海关岗""公安岗"）→ 按该岗位方向搜热点选题
   - **用户未指定岗位** → 按下方通用选题策略执行

2. **通用选题策略**（用户未指定岗位时）：
   - 用 WebSearch 搜**近 1-2 周**的公务员面试热点话题、政策类新闻、社会现象
   - **首选题材**：热点话题、政策类、社会现象（这类题有时效性，也最容易暴露假大空）
   - **避免**：过于专业的岗位题材（如"海关稽查""税务稽查"等需专业知识的题），除非用户指定

3. **选 2-3 个选题**，每个附一句反常识破题思路，让用户选择：
   - 格式：`选题 A：XXX — 反常识破题：不是 X，是 Y`
   - 用户选后进入步骤 2

**选题要求**：
- 选题要"看着简单、实有政策深度"——这类题最容易暴露假大空
- 破题必须**反常识/反模板**（如"不是基层变懒了，是考核方式在逼基层装忙"）
- 优先选有时效性的热点（近 1-2 周新闻/政策），其次选经典高频题

### 步骤 1.5：选择内容模式（**选题后必问**）

用户选定选题后，**必须用 `AskUserQuestion` 工具询问**用哪种模式生成内容：

| 模式 | 说明 | 适合场景 |
|---|---|---|
| **常规模式** | 3 层 30/40/30 + 5 段增值完整长帖（段位表全填） | 政策深度题、综合分析题、需要完整拆解的复杂话题 |
| **对比卡模式** | 把"3 个倒错 vs 3 个校正"改为"低分答法 vs 高分答法"对比卡片，段位表相同但内容编排变化 | 人际沟通题、应急处突题、对比感强的题型 |

**fallback**：如果 runtime 不支持交互工具（`AskUserQuestion` 不可用），默认走常规模式，在报告中标注"未询问模式，使用默认常规模式"。

**题型适配检查**：用户选对比卡但选题属于"综合分析/哲理启示"类时，提示"对比卡模式可能不适合，建议常规模式"。用户确认仍用对比卡 -> 尊重选择继续。

**对比卡模式核心变化**（详见 `references/content-strategy.md`）：段位表和 JSON 字段不变，脚本不改。第二层->低分答法、第三层->高分答法，每组形成"对比卡"更易截屏收藏。
