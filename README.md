# Shawn 自用 Skill 合集

本仓库包含以下 4 个自定义 skill：

| Skill | 说明 |
|-------|------|
| zhankai-shuoshuo-post | 自动化生成"考官想听的·展开说说"系列小红书长帖 docx |
| gongkao-interview-question | 为公考面试结构化题库批量生成 Obsidian md 文件 |

## 安装

将对应 skill 目录复制到 `~/.trae-cn/skills/` 即可使用。
